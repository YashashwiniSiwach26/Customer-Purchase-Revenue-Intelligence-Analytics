# 📊 Customer Purchase & Revenue Intelligence Analytics

An end-to-end data analytics project that transforms raw customer shopping data into actionable business insights using **Python, SQL, and Power BI**.

This project demonstrates a complete analytics workflow — from data cleaning and exploratory analysis to SQL-based business analysis and interactive dashboard development — with a focus on **customer behavior, purchasing patterns, revenue drivers, and customer segmentation**.

---

## 🎯 Project Objective

The objective of this project is to analyze customer purchasing behavior and identify patterns that can help businesses improve:

* Customer segmentation
* Revenue generation
* Customer retention
* Product performance
* Purchase behavior
* Marketing and sales strategies

The project follows an industry-oriented workflow to convert raw transactional data into meaningful business intelligence.

## 🧹 Data Preparation & Exploratory Data Analysis

The project begins by loading and exploring the raw customer shopping dataset using Python.

### Key activities:

* Imported raw customer transaction data
* Inspected dataset structure and data types
* Identified missing and inconsistent values
* Removed duplicate records
* Standardized categorical variables
* Cleaned and transformed relevant columns
* Performed exploratory data analysis
* Created derived features for deeper analysis
* Investigated customer demographics and purchasing patterns

Python and Pandas were primarily used to prepare the dataset for downstream SQL analysis and visualization.

---

## 🗄️ SQL Business Analysis

After preprocessing, the cleaned dataset is analyzed using SQL to answer practical business questions.

### Business questions explored:

* Which customer segments generate the highest revenue?
* Which products and categories perform best?
* How does purchasing behavior vary across demographics?
* Which customers demonstrate strong purchase frequency?
* What factors influence customer spending?
* Which categories have the highest average purchase value?
* How do discounts relate to customer purchases?
* What are the major revenue-generating customer groups?

SQL queries are designed to simulate real-world business intelligence requirements and demonstrate analytical problem-solving.

## 📊 Power BI Dashboard

The analyzed data is connected to Power BI to create an interactive business intelligence dashboard.

### Dashboard includes:

* **Total Revenue**
* **Total Customers**
* **Total Purchases**
* **Average Purchase Value**
* Customer segmentation
* Revenue by product category
* Purchase behavior by demographic group
* Sales and purchasing trends
* Discount and purchase analysis
* Interactive filters and slicers

The dashboard provides stakeholders with an easy-to-understand overview of customer behavior and revenue performance.
